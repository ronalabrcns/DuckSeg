Introduction
============

DuckSeg provides utilities for cell image segmentation, tracking, and analysis. It includes:

- Cell segmentation using deep learning models
- Experiment loading and management
- Image transformation and preprocessing
- Video visualization and analysis
- Outlier detection and filtering

Getting Started
===============

Installation
------------

To install DuckSeg, clone the repository and install dependencies::

    git clone https://github.com/ronalabrcns/DuckSeg.git
    cd DuckSeg
    pip install -e .
